# รายงานความเสียหายจากพายุฤดูร้อน 3 พ.ค. 2567

`KKN_20240503_reports.csv` — 19 จุดระดับตำบล รวบรวมจากข่าวและรายงาน ปภ.

| คอลัมน์ | ความหมาย |
|---|---|
| `lat`, `lon` | จุดกึ่งกลาง (representative point) ของตำบล จาก OpenGISData-Thailand — **ไม่ใช่ตำแหน่งความเสียหายจริง** |
| `time_LT`, `time_UTC` | เวลาที่รายงาน (ว่าง = ระบุเพียง "กลางคืน") |
| `time_quality` | `exact` (ปภ. ระบุเวลา), `approx` (ประมาณ), `night` (ไม่ระบุเวลา) |
| `hazard` | ลมกระโชกแรง / ลมแรง / ลูกเห็บ ตามที่ข่าวระบุ (ข่าวไม่กล่าวถึงลูกเห็บ ≠ ไม่มีลูกเห็บ) |
| `houses_damaged`, `injured`, `deaths` | ตัวเลขตามรายงาน ณ วันที่ 3–4 พ.ค. 2567 (ว่าง = ไม่ระบุแยกรายตำบล) |
| `source` | แหล่งข่าว |

ข้อมูลนี้ใช้เพื่อการเรียนการสอน ตัวเลขความเสียหายอาจเปลี่ยนแปลงตามการสำรวจภายหลัง
